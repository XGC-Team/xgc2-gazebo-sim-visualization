# XGC2 Gazebo Sim Visualization

ROS Noetic RViz visualization tools for XGC2 Gazebo Classic simulations.

This repository contains the `gazebo_sim_visualization` package. It can be
placed directly under a catkin workspace `src/` directory.

## Build

```bash
source /opt/ros/noetic/setup.bash
catkin_make
```

## Launch

```bash
roslaunch gazebo_sim_visualization gazebo_auto_visualization_rviz.launch
```
